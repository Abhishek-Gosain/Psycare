# PsyCare — Mental Health Awareness & Support App

**PsyCare** is a Unity-based Android application designed to promote mental health awareness and make psychological information and counselling resources more accessible. The application brings educational content, interactive psychological assessments, virtual counselling support, and professional counsellor discovery into one mobile platform.

The project focuses on encouraging mental health awareness, reducing stigma surrounding psychological disorders, and helping users explore appropriate support resources.

> **Repository Notice:** This repository showcases the PsyCare project through application screenshots, feature documentation, and technical details. The Unity source code and compiled APK have intentionally not been published for security and intellectual property protection reasons.

## ✨ Key Features

### 1. Mental Health Awareness
- Provides educational information about mental health and psychological well-being.
- Presents information about common psychological disorders.
- Covers symptoms, treatment information, and ways to seek appropriate support.
- Aims to improve awareness and reduce misconceptions surrounding mental health.

### 2. Interactive Psychological Assessments
- Includes psychological assessment concepts for exploring areas such as anxiety, stress, and self-concept.
- Helps users engage with structured psychological questionnaires.
- Supports mental health awareness through assessment-oriented interactions.

*These assessments are intended for awareness and informational purposes and should not be treated as a substitute for professional diagnosis.*

### 3. Virtual Counsellor Support
- Incorporates a virtual counselling concept to guide users through mental health information.
- Connects educational resources with assessment-oriented guidance.
- Provides an approachable way to explore mental health topics within a mobile application.

### 4. Professional Counsellor Discovery
- Designed to help users explore nearby clinical psychologists and counselling resources.
- Supports access to professional mental health assistance.
- Includes a map-oriented clinic discovery concept.

### 5. Appointment Booking Workflow
- Designed around booking appointments with professional counsellors.
- Includes appointment-related interactions and confirmation workflows.
- Aims to simplify the process of finding and accessing counselling services.

### 6. Online Counselling and Communication
- Envisions online counselling and video-based communication.
- The project documentation references the Agora SDK in connection with communication functionality.
- Supports the broader goal of making counselling resources more accessible.

### 7. User-Friendly Mobile Experience
- Developed as an Android application using Unity.
- Brings multiple mental health awareness and support concepts together in a single mobile experience.
- Uses an interactive application interface to make information easier to explore.

## 🏗️ Project Overview

PsyCare was developed to address the fragmentation of mental health information and support resources across different platforms.

The application brings together several related areas:

- **Awareness:** Access to educational information about psychological disorders.
- **Assessment:** Structured psychological questionnaires and assessment-oriented interactions.
- **Guidance:** A virtual counsellor concept for exploring mental health resources.
- **Professional support:** Discovery of counselling resources and appointment-related workflows.

The project explores how an interactive mobile application can help users access mental health information and discover relevant support options more conveniently.
